
## 3. 自提：跑通第一笔订单

全新演练库，选 1 份进口香蕉，单价应为 ¥3.98，不用优惠券。

1. [ ] 顾客加入购物车，去结算，选“到店自提”。商品 ¥3.98、配送 ¥0.00、应付 ¥3.98。
2. [ ] 提交订单，记下订单号。此时待付款，库存被预占；还不应显示已付款或已完成。
3. [ ] 点“模拟失败”。应提示失败，仍为待付款，没有新增模拟扣款。
4. [ ] 点“模拟微信付款”。应变为待接单，已付 ¥3.98。刷新不能再扣一次钱。
5. [ ] 店长找到同一订单，依次“接单并拣货 → 剩余商品全部拣齐 → 完成打包”。不应允许跳过拣货直接完成。
6. [ ] 顾客刷新订单，出现 6 位自提码。记录后切店长，故意输入一个不同的 6 位码：应拒绝，订单仍待自提。
7. [ ] 输入正确码“确认核销”，应已完成；顾客刷新也应已完成，库存不再额外减少。
8. [ ] 店长进入实验室，点一次“重试任务”，再检查对账。应显示所有账本一致。

结算报价约 2 分钟有效。若中间停留太久，出现过期提示应返回结算重新取得报价，不是绕过错误继续提交。未支付订单约 15 分钟过期；本指南关闭了自动任务，需要店长点“重试任务”触发检查。

## 4. 配送、缺货退款、故障恢复、售后

10. [ ] 顾客刷新：订单已完成，缺货退款 ¥3.59 仍保留。地图/轨迹不能当作真实骑手定位。

11. [ ] 顾客在此完成订单填写“验收售后”并申请剩余实付退款；仅申请不能直接显示已到账。

13. [ ] 再重试、刷新，不能超过原实付款；缺货/售后退款不能凭空把没有实际退回的货品加入库存。
14. [ ] 只做第 3、4 节且没有额外订单时：累计 2 笔订单、模拟收款 ¥34.72、退款 ¥30.74、净收款 ¥3.98；账本一致。
