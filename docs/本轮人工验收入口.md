## Linux 启动

在已安装依赖的项目目录运行（数据目录必须位于源码之外）：

```bash
.venv/bin/python -m backend.mock_demo /home/vimalinx/.local/state/jingman-acceptance-20260918 --no-worker
```

换电脑时替换为自己的源码外绝对目录。默认端口 8873/8874，已占用时不会抢占或停止其他进程。按 Ctrl+C 停止本次启动的服务，保留演练记录。`--no-worker` 表示退款、打印等队列需店长在“故障演练”中手动重试。

## 推荐验收顺序

1. 顾客：连接 → 首页 → 分类 → 商品详情 → 加减购物车 → 结算 → 地址 → 优惠券 → 模拟付款 → 订单列表和详情 → 我的。
2. 店长/拣货员：工作台统计跳转 → 接单 → 缺货处理 → 拣货打包 → 自提备好；切回顾客确认首页持续显示核销码，完成核销后消失。
3. 配送员：任务列表 → 取货 → 模拟送达；再由顾客检查订单状态与售后入口。
4. 店长：商品库存 → 本地模拟条码查询 → 模拟 POS → 故障与退款重试 → 对账。完整营销、商品编辑、门店设置与导出在网页测。
5. 第二顾客、第二门店：检查不能查看或修改其他用户/门店的订单。

小程序共 15 页：连接、首页、分类、商品详情、购物车、结算、订单列表、订单详情、我的、地址、优惠券、工作台、库存、故障演练、配送任务。订单详情等页面需先产生相应演练订单，不能用空白页面代替验收。
